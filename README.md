# Cloud-Lab# Cloud Infrastructure Lab

Hands-on cloud engineering projects demonstrating Azure and AWS administration, automation, identity management, and real-world sysadmin workflows.

This lab is built to showcase practical skills used in enterprise environments — including VM deployment, cloud identity, automation, backup, monitoring, and hybrid cloud operations.

## 🛠️ Projects Included

### 🔹 Azure VM Deployment (PowerShell + Azure CLI)
Automates creation of a VM, networking, NSG rules, and tagging.

### 🔹 Azure AD User Provisioning
Creates cloud-only or hybrid users with proper roles and licensing.

### 🔹 AWS EC2 Deployment (Bash + AWS CLI)
Deploys an EC2 instance with security groups and IAM roles.

### 🔹 IAM Security Audit
Exports IAM users, roles, MFA status, and access keys for compliance.

### 🔹 Hybrid Identity Lab
Demonstrates Azure AD Connect concepts and hybrid join automation.

### 🔹 Cloud Backup & Monitoring
Scripts for snapshot backups, CloudWatch metrics, and Azure Monitor alerts.
